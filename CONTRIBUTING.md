# Contribuir

Gracias por ayudar a mejorar Mouse for Fools.

## Reportar un problema

Abre un issue con versión de Windows, versión del proyecto, pasos para reproducir, resultado esperado y resultado observado. Usa ventanas de prueba y elimina datos personales de capturas y logs. No incluyas contraseñas ni documentos de terceros.

## Proponer cambios

1. Explica el problema en un issue si el cambio altera controles o comportamiento.
2. Crea un fork y una rama para tu cambio.
3. Instala `.[dev]` en un entorno virtual de Windows.
4. Añade o ajusta las pruebas de comportamiento necesarias. Ejecuta los comandos de validación del README.
5. Abre un pull request con el problema, la solución y lo que comprobaste.

Conserva los mecanismos de desactivación y cierre de emergencia. No pruebes clics o arrastres sobre aplicaciones con operaciones importantes. Una prueba automatizada no reemplaza la comprobación física del teclado y el cursor.

## Áreas de colaboración

- Pruebas en otros equipos Windows y teclados compactos.
- Mejoras de ayuda y navegación íntegra por teclado.
- Configuración de controles, previo diseño y discusión.
- Validación del portable y documentación de empaquetado reproducible.

Las contribuciones de código propio a este repositorio se realizan bajo MIT; conserva la atribución y los avisos aplicables. No copies código o recursos sin derechos para aportarlos.
