# Reportar un problema de seguridad

Para un posible fallo de seguridad, utiliza el reporte privado de vulnerabilidades de GitHub si está habilitado en la pestaña Security. Si no está disponible, abre un issue solicitando un canal privado, sin publicar detalles de explotación ni datos sensibles.

No compartas contraseñas, pulsaciones, contenido de documentos o logs sin revisar. Las correcciones se publicarán con su alcance comprobado; no se garantiza un plazo de respuesta.
